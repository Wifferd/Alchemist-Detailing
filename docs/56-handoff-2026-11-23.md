## 7. Lessons from the last stretch

- Container and worker restarts kill background workflows. Keep progress logs in files, resume workflows with
  `resumeFromRunId`, and check `supabase_migrations.schema_migrations` before re-applying any part.
- This container's proxy can't reach thealchemistdetailing.com or the supabase.co hosts: verify the live page with
  Vercel `web_fetch_vercel_url`, and the database as the anon role in SQL.
- Playwright has no collapsing toolbar, so iPhone Safari's `svh ≠ lvh` needs `tools/qa/mksim.py` + `toolbar.py`.
- The GitHub hook has missed pushes before: if a deployment for the new sha is missing, create it with
  `create_deployment` (gitSource org Wifferd, repo Alchemist-Detailing, ref main, sha).
