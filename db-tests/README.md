# Migration 001 tests

These are the suites that checked Migration 001 before it went live: 472 checks across access, booking, staff, review and round-8 behaviour, plus every one of the 6,480 price combinations (`m001_tests_pricing.sql`, generated by `gen_pricing_matrix.py`).

They were run in two places:

- **The test project ("Alchemist Test"),** pasted into its SQL Editor after the migration. That's the reliable way to re-run them: they need Supabase's real Auth and Storage schemas.
- **A local Postgres 16** in the cloud workspace where this was built, with Supabase's schemas stubbed. The shell scripts (`run_local.sh`, `concurrency_local.sh`, the `dryrun_*` scripts) still point at that machine: `PGHOST=/home/claude/.pgtest`, port 54329. Set `PGHOST`, `PGPORT` and `PGUSER` for your own Postgres before using them.

Order that passes: `m001_framework.sql`, `m001_fixtures.sql`, then the `m001_tests_*.sql` suites; run the concurrency script once, on its own database.
